Floating overlay:
- Dashboard me ENABLE FLOATING OVERLAY dabayein.
- Android ke "Display over other apps" permission ko allow karein.
- App me wapas aakar button dobara dabayein.
- Floating panel doosri apps ke upar, including Free Fire during normal gameplay,
  dikh sakta hai if Android/device policy allows overlays.
- Red header ko drag karke move karein. Header par tap karke overlay close karein.

Buttons AIM BOT, AUTO HEADSHOT, MOVEMENT, FLY, GHOST sirf demo labels/buttons hain.
Ye Free Fire ko control, modify, inject, automate, ya cheat nahi karte.

APK banane ka tarika:
1. ZIP extract karein.
2. Android Studio me project folder open karein.
3. Gradle sync complete hone dein.
4. Build > Build Bundle(s) / APK(s) > Build APK(s).
5. APK app/build/outputs/apk/debug/app-debug.apk me milegi.

Note: Yeh source project hai, ready-made APK nahi.
